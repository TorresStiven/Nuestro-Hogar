# Historial de versiones

## 0.1 — Prototipo funcional (2026-11-08)

Primera versión del proyecto para validar la idea y aplicar conocimientos de
desarrollo web.

- Se creó la portada con navegación compartida y diseño adaptable.
- Se agregó Convivencia para crear, asignar, completar, filtrar y eliminar
  tareas, con indicadores de esfuerzo.
- Se agregó Nuestros Instantes para guardar recuerdos y fotografías en el
  navegador.
- Se incorporó persistencia con `localStorage` e IndexedDB.
- Se añadieron validaciones básicas de los datos guardados y estados de respaldo
  para fotos no disponibles.
- Se documentaron la visión, arquitectura y funcionalidades.

### Pendiente para siguientes versiones

- Módulo de compras e inventario.
- Fechas especiales con datos reales.
- Ruleta de responsabilidades.
- Sincronización entre dispositivos y respaldo remoto.
- Pruebas automatizadas y publicación web.

Las fechas de este historial identifican entregas del proyecto, no garantizan
que cada funcionalidad se haya desarrollado en un solo día.
